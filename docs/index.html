Explore Dataset View on GitHub

Overview

This replication package contains the dataset, classification results, and analysis notebook for our empirical study. We analyzed 937 refactoring PRs generated by 5 AI coding agents (Devin, OpenAI Codex, GitHub Copilot, Cursor, and Claude Code) across 856 open-source GitHub repositories.

Focus Areas:

  • Human reviewer feedback analysis
  • Refactoring intent classification
  • Agent performance and acceptance rates
  • Common reasons for PR rejection

Overview of the study design

Study Design

RQ1: Refactoring Patterns

How do AI agents approach refactoring in open-source projects? We classified PRs into a taxonomy of concerns expressed by human reviewers.

RQ2: Review Analysis

What are the characteristics of the review process for agentic PRs? We analyzed the engagement and sentiments of human reviewers.

Dataset Description

The dataset is structured into several CSV files providing comprehensive information about PRs, reviews, and classifications.

File Description
accepted_with_reviews.csv Raw PR data for merged refactoring requests.
rejected_with_reviews.csv Raw PR data for closed/rejected refactoring requests.
pr_review_comments.csv All human and bot review comments.
taxonomy_*_final.csv RQ1 classification results with categories and evidence.

Review Taxonomy

QUALITY

Code smell, Technical debt, Design pattern, Coding convention, Documentation.

REFACTORING

Correctness, Behavior preservation, Co-occurrence with changes, Domain constraints.

OBJECTIVE

Unclear goal, Unknown benefit, Side effects, Scope change, Feature support.

TESTING

Lack of coverage, Absence of result, Poor test quality.

INTEGRATION

Configuration issue, Merge conflict, API management, Build failure.

MANAGEMENT

No review activity, Forgotten review, Dependency, Guideline violation.

How to Reproduce

# Clone this repository

git clone https://github.com/smilevo/agentic-refactoring-prs-replication.git

# Install requirements

pip install pandas anthropic scipy

Follow these steps in taxonomy_classification.ipynb:

  1. Load and verify the three CSV files
  2. Filter bot comments and build reviewer lookup
  3. Define the taxonomy classification prompt and Claude API call
  4. Run classification on all PRs with independent human reviewer comments
  5. Auto-tag PRs with no human reviewer comments
  6. RQ1 analysis & summary table generation
  7. Export final classified CSVs
